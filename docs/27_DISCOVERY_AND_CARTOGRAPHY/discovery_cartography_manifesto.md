# Discovery and Cartography Manifesto

## Purpose
Make discovery the central reward. Mapping should be personal, partial, fallible, and emotionally meaningful.

## Design Rules
- Perfect maps kill dread.
- No maps kills learning.
- Personal annotations matter.
- Global first discoveries should feel legendary.
- Route memory is gameplay.
- Contradictory maps are valid horror tools if used sparingly.

## Implementation Notes
Create layered map data: player-known chunks, personally annotated traces, confirmed exits, disputed exits, unknown-level records, anchor routes, and global discovery metadata.

## Codex Instructions
Do not add minimap certainty by default. Build tools that reward exploration without flattening the mystery.

## Common Failure Modes
- Treating this as generic survival or horror content.
- Adding complexity before the base loop proves itself.
- Ignoring scale, silence, absence, and uncertainty.
