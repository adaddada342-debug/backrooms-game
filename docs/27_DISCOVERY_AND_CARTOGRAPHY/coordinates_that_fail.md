# Coordinates That Fail

## Purpose
Coordinate systems should work locally and fail globally.

## Design Rules
- Mapping must help memory without restoring total certainty.
- Discovery is meaningful when it changes understanding.
- Use diegetic presentation when possible.

## Implementation Notes
Create save data structures, annotation tools, route nodes, discovery records, and minimal UI.

## Codex Instructions
Do not implement a full GPS minimap before prototype testing. Build journal/map data first.

## Common Failure Modes
- Treating this as generic survival or horror content.
- Adding complexity before the base loop proves itself.
- Ignoring scale, silence, absence, and uncertainty.
