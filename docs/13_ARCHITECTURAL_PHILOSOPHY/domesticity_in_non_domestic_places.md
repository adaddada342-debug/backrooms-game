# Domesticity In Non-Domestic Places

## Purpose
Tiny signs of living in offices, malls, stations, and schools create emotional charge.

## Emotional Target
Survival leaves intimate stains on public architecture.

## Design Rules
- Start from a real-world building logic.
- Remove occupants before removing function.
- Contradict purpose subtly before using obvious surrealism.
- Keep the contradiction memorable and restrained.

## Implementation Notes
- Use reference boards for real building layouts.
- Create module sets with service/back-of-house spaces.
- Define macro/micro landmarks.
- Store the dominant contradiction in each LevelRecipe.

## Codex Instructions
- Never add enemies to compensate for weak architecture.
- Ask what the place used to do before deciding what is wrong with it.
- Validate that the space still makes sense before making it impossible.

## Common Failure Modes
- Generic hallway spam.
- Random rooms with no implied function.
- Overexplaining architecture through lore notes.
