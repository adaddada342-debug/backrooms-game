# Level Archetype Trace Weights

## Purpose
Match trace categories to architecture type.

## Emotional Target
believable place memory

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Airports prefer waiting, communication, security, service, luggage-like traces.
- Schools prefer childhood, bureaucracy, waiting, maintenance.
- Poolrooms prefer water, maintenance, leisure, impossible architecture.
- Hotels prefer hospitality, sleep, security, domesticity-in-public.

## Implementation Notes
- Create weighted tables per level recipe.
- Let rare category contamination create wrongness.
- Reject traces that break the level thesis without purpose.

## Codex Instructions
- Implement this as data-driven rules, not hardcoded one-off prop spam.
- Add editor/debug validation where practical.
- When unsure, reduce trace density.

## Common Failure Modes
- Random prop scatter.
- Too many clues in one space.
- Immediate explanation.
- Theme-breaking object placement.
