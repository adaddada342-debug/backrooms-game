# Anti-Gore Rule

## Purpose
Keep psychological horror from collapsing into shock imagery.

## Emotional Target
dread without cheap disgust

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Avoid graphic gore as routine evidence.
- If injury traces exist, keep them restrained and partial.
- Prefer abandoned routines and maintenance scars over bodies.

## Implementation Notes
- Use discoloration, broken procedure, missing supplies, indirect signs.
- Never make gore the main language of the Backrooms.

## Codex Instructions
- Implement this as data-driven rules, not hardcoded one-off prop spam.
- Add editor/debug validation where practical.
- When unsure, reduce trace density.

## Common Failure Modes
- Random prop scatter.
- Too many clues in one space.
- Immediate explanation.
- Theme-breaking object placement.
