## Emotional Target

## Non-Negotiable Design Rules
- Do not choose tech for hype.
- Prototype emotional feel first.
- Keep schemas engine-agnostic when possible.
- No custom engine.

## Implementation Notes
- Separate content data from engine implementation.
- Use source control.
- Keep folder structures strict.

## Codex Instructions
- If engine-specific code is added, document why.

## Common Failure Modes
- Endless engine debate.
- Rebuilding core systems repeatedly.
- Custom-engine rabbit hole.
- Visual obsession before gameplay proof.
