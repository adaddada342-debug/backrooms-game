# Trace Category: Sleep, waiting, and fatigue

## Purpose
Defines how to use the `Sleep, waiting, and fatigue` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Sleep, waiting, and fatigue`. Sample entries:

- 351. Pillow indentation but cold sheets: recent enough to imagine, old enough to doubt; who slept here?
- 352. Alarm clock set but unplugged: intention stripped of function; what wake-up mattered?
- 353. Queue ticket clenched in a dead hand-shaped plaster cast: waiting embodied cruelly; what service never arrived?
- 354. Recliner chair facing a blank corner: exhaustion without entertainment; what was worth staying awake for?
- 355. Energy drink can pyramid beside a map: mania of endurance; who stopped sleeping to understand the place?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 351-375.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
