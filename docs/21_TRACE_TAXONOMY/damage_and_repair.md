# Trace Category: Damage and repair

## Purpose
Defines how to use the `Damage and repair` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Damage and repair`. Sample entries:

- 176. One smashed panel among otherwise intact walls: precise violence; what happened *only there*?
- 177. Chair leg repaired with medical tape: survival improvisation; who used whatever they had to keep order?
- 178. Burned patch on ceiling tiles: heat above the room; what travelled overhead?
- 179. Carpet peeled back and never relaid: investigation trace; what was somebody trying to inspect underneath?
- 180. Wall patched around a body-shaped hole: impossible event normalised by maintenance; what passed through?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 176-200.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
