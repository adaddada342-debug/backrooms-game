# Trace Category: Timekeeping, memory, and self-loss

## Purpose
Defines how to use the `Timekeeping, memory, and self-loss` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Timekeeping, memory, and self-loss`. Sample entries:

- 451. Four clocks in one room agreeing on the wrong time: consensus error; what larger system are they following?
- 452. Calendar repeatedly reset to the same month: denial or cycle; who refuses to move forward?
- 453. Diary entries skipping only the safe days: selective memory; what happened on the omitted ones?
- 454. Photo wall containing your current corridor from an angle you’ve never seen: future or forgotten past; who took it?
- 455. Watch stopped only when held in one corner: localised time injury; what happened there?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 451-475.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
