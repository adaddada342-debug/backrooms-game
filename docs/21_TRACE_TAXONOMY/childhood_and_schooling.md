# Trace Category: Childhood and schooling

## Purpose
Defines how to use the `Childhood and schooling` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Childhood and schooling`. Sample entries:

- 201. Tiny plastic chair in a corporate corridor: category collision; why was a child-sized object needed here?
- 202. School timetable posted in an adult waiting room: memory bleed; how did this migrate?
- 203. Locker door covered in stickers from two decades ago: preserved adolescence; who never removed them?
- 204. Crayon mark above adult shoulder height: impossible child evidence; how did it get there?
- 205. Lost-property bin full of only one shoe sizes: asymmetrical childhood trace; where are the other halves?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 201-225.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
