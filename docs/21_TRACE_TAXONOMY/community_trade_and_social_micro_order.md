# Trace Category: Community, trade, and social micro-order

## Purpose
Defines how to use the `Community, trade, and social micro-order` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Community, trade, and social micro-order`. Sample entries:

- 376. Shelf marked “take one, leave one” with nothing left: trust exhausted; who depended on this exchange?
- 377. Barter board listing batteries for stories: scarcity and companionship becoming currency; what stories are worth power here?
- 378. Communal kettle chained to a pipe: shared necessity with distrust; who started stealing it?
- 379. Message jar full of route tips: collective intelligence under isolation; how many contributors are still alive?
- 380. Handwritten menu in a room with only canned goods: civilisation performance; who is pretending normal service still matters?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 376-400.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
