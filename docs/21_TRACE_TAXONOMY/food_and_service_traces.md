# Trace Category: Food and service traces

## Purpose
Defines how to use the `Food and service traces` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Food and service traces`. Sample entries:

- 101. Vending machine still functioning: automated life beyond human life; who refills it?
- 102. One expired sandwich behind fresh crisps: inconsistent maintenance; what supply chain still operates?
- 103. Cafeteria tray with crumbs but no meal: vanished diner; what interrupted the break?
- 104. Sodden napkin on a plastic seat: fresh occupancy; how recently was someone eating here?
- 105. Coffee machine with the clock set correctly: accurate time in a wrong place; who maintains it?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 101-125.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
