# Trace Category: Medical and sanitary traces

## Purpose
Defines how to use the `Medical and sanitary traces` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Medical and sanitary traces`. Sample entries:

- 226. Examination curtain drawn around nothing: privacy without patient; who needed shielding last?
- 227. Disposable gloves scattered but unopened box full: panic over policy; why did procedure break?
- 228. Sickness bag tucked into a seatback: anticipated nausea; what journey is this room pretending to be?
- 229. Hand-sanitiser bottle empty beside a full spare: recent fear; what outbreak made cleanliness urgent?
- 230. Blood pressure cuff hung on a coat hook: care tools treated casually; who redefined the room?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 226-250.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
