# Trace Category: Bureaucratic remnants

## Purpose
Defines how to use the `Bureaucratic remnants` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Bureaucratic remnants`. Sample entries:

- 51. Visitor sign-in sheet ending mid-day: narrative cut-off; what happened after the final entry?
- 52. “Please queue here” tape on an empty carpet: social ritual without society; what crowd is imagined?
- 53. Office org chart with blank photo spaces: depersonalised order; who belonged to this structure?
- 54. Outdated fire drill poster still pristine: permanent preparedness; what emergency shaped the culture here?
- 55. Abandoned complaint form box: unvoiced grievance; what problems were once common enough to structure?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 51-75.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
