# Trace Category: Movement and navigation

## Purpose
Defines how to use the `Movement and navigation` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Movement and navigation`. Sample entries:

- 151. Hand-drawn arrows correcting official signage: human counter-map; who knew the building better than the building knew itself?
- 152. Carpet worn only along one diagonal: preferred illegal route; why does everyone cut this way?
- 153. Scuff marks around a false wall: repeatedly tested boundary; how many people suspected an opening?
- 154. “Shortcut” scribbled on a duct marker: informal geography; who trusted this note?
- 155. String line tied from column to column: improvised anti-lost system; how often does the layout betray memory?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 151-175.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
