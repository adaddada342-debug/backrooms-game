# Trace Category: Interrupted presence

## Purpose
Defines how to use the `Interrupted presence` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Interrupted presence`. Sample entries:

- 1. Half-drunk bottle: abrupt interruption; who stopped mid-sip, and what interrupted them?
- 2. Warm office chair: recent absence; who stood up seconds ago, and where did they go?
- 3. Uncapped marker: unfinished task; what was being labelled, and why was it abandoned?
- 4. Receipt half-torn from a printer: broken routine; what transaction almost completed?
- 5. Charger still plugged into the wall: ownerless dependence; whose device mattered enough to leave behind?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 1-25.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
