# Trace Category: Improvised habitation

## Purpose
Defines how to use the `Improvised habitation` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Improvised habitation`. Sample entries:

- 76. Nest of blankets in a storage alcove: fragile claim to place; who tried to make this survivable?
- 77. Books stacked as a bedside table: domesticity by necessity; what life was rebuilt from scraps?
- 78. Mug and toothbrush arranged with care: stubborn normality; who is maintaining personhood here?
- 79. Tin of biscuits hidden behind a vent: secrecy inside scarcity; who feared being found?
- 80. Extension lead feeding a lamp from a maintenance outlet: soft comfort stolen from infrastructure; who carved out this refuge?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 76-100.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
