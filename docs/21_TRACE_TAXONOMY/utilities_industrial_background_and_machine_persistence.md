# Trace Category: Utilities, industrial background, and machine persistence

## Purpose
Defines how to use the `Utilities, industrial background, and machine persistence` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Utilities, industrial background, and machine persistence`. Sample entries:

- 476. Pump room running smoothly beside flooded halls: machine order indifferent to human disorder; who services it?
- 477. Conduit bundle labelled for floors that do not exist: infrastructure predicting impossible architecture; what was the system built for?
- 478. Generator fuel log still current: survival by machine religion; who keeps feeding it?
- 479. Boiler gauge reading “normal” in a room that feels all wrong: machine normality mocking human feeling; whose normal counts?
- 480. Relay clicking every eleven seconds: hidden process with exact rhythm; what cycle is completing unseen?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 476-500.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
