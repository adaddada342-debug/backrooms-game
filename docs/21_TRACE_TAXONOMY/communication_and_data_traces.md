# Trace Category: Communication and data traces

## Purpose
Defines how to use the `Communication and data traces` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Communication and data traces`. Sample entries:

- 276. Voicemail light blinking on a desk phone: unheard message waiting eternally; who never picked up?
- 277. Fax machine paper curled with age next to fresh toner: old and current media coexisting; who still receives documents here?
- 278. Chat log printed and highlighted by hand: digital fear made physical; what conversation needed holding?
- 279. Label printer spitting blank tape: system exhaustion; what identity failed to print?
- 280. Password wall hidden behind a framed picture: secret normality; who trusted that hiding place?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 276-300.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
