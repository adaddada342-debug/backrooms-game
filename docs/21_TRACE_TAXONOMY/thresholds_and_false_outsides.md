# Trace Category: Thresholds and false outsides

## Purpose
Defines how to use the `Thresholds and false outsides` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Thresholds and false outsides`. Sample entries:

- 426. Sunlight strip under a door that opens into fluorescent night: hope weaponised; where was that light coming from?
- 427. Emergency exit handle warm to the touch in a cold wing: promise of elsewhere; who tried it recently?
- 428. Breeze carrying street noise through a bricked-up loading bay: outside implied but denied; what world is on the other side?
- 429. Dust-free doormat before a room that leads nowhere: hospitality at an absent threshold; who keeps placing mats?
- 430. Welcome sign facing inward: messaging the trapped, not arrivals; who is the intended audience now?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 426-450.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
