# Trace Category: Leisure, retail, and hospitality traces

## Purpose
Defines how to use the `Leisure, retail, and hospitality traces` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Leisure, retail, and hospitality traces`. Sample entries:

- 251. Arcade token under a filing cabinet: entertainment residue in dead workspace; how did play reach here?
- 252. Hotel keycard with the logo rubbed off: anonymous hospitality; what room did it belong to?
- 253. Popcorn kernel caught in pool drain: multiple leisure systems bleeding together; what route connected cinema to water?
- 254. Prize-ticket spool in a server room: childhood reward trapped in infrastructure; who stored it here?
- 255. Folded napkin shaped like a swan in a maintenance sink: service ritual surviving displacement; who still performs for nobody?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 251-275.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
