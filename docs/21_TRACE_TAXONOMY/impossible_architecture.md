# Trace Category: Impossible architecture

## Purpose
Defines how to use the `Impossible architecture` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Impossible architecture`. Sample entries:

- 401. Door opening to the back of itself: direct ontological insult; how can passage and return be the same act?
- 402. Identical room rotated ninety degrees with gravity unchanged: bodily mismatch; which orientation is real?
- 403. Pillar core containing a full corridor: impossible internal volume; what else is hidden inside solids?
- 404. Drop ceiling above a room with visible clouds: stack conflict; what layer does the ceiling belong to?
- 405. Window revealing a room you left an hour ago: temporal fold; are you looking across space or time?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 401-425.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
