# Trace Category: Ritual and symbolic behaviour

## Purpose
Defines how to use the `Ritual and symbolic behaviour` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Ritual and symbolic behaviour`. Sample entries:

- 326. Circle of chairs facing an unplugged TV: collective waiting turned ritual; what were they expecting?
- 327. Coins stacked on a radiator: superstition or signal; what bargain was imagined?
- 328. Candles burned down around a maintenance hatch: reverence for infrastructure; what inhabits that opening in rumour?
- 329. Repeated phrase written on multiple walls in different hands: emergent doctrine; when did coincidence become belief?
- 330. Thread tied around doorknobs in one wing: folk border-making; what is being marked off?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 326-350.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
