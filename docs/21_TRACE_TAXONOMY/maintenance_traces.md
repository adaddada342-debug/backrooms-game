# Trace Category: Maintenance traces

## Purpose
Defines how to use the `Maintenance traces` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Maintenance traces`. Sample entries:

- 26. One fluorescent tube newer than the rest: invisible care; who keeps this corridor alive?
- 27. Ceiling tile replaced but mismatched: repair without aesthetic concern; what happened above it?
- 28. Painter’s tape labels on pipes: system legibility for absent workers; who still needs these instructions?
- 29. Calibration sticker dated last week: recent technical attention; what machine remains important?
- 30. Ladder locked open beneath a dead light: deferred repair; who meant to come back?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 26-50.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
