# Trace Category: Weather, water, and biological intrusion

## Purpose
Defines how to use the `Weather, water, and biological intrusion` trace category in liminal spaces.

## Emotional Target
implied story without visible actors

## Source Basis
Source report environmental storytelling category `Weather, water, and biological intrusion`. Sample entries:

- 301. Condensation on one interior wall: climate mismatch; what space is on the other side?
- 302. Puddle rippling without visible drip source: unstable causality; what is disturbing the surface?
- 303. Damp tide mark rising and falling between visits: living architecture; what rhythm controls it?
- 304. Smell of cut grass in a sealed basement: outside memory invading inside; where is it coming from?
- 305. Single vine threaded through a fluorescent fitting: biological opportunism; how did it enter the ceiling void?

## Design Rules
- Use this category only when it supports the level archetype and psychological stage.
- Pick one or two strong traces rather than many weak ones.
- Every trace must create a question and preserve absence.
- Prefer precise physical placement over abstract symbolism.

## Implementation Notes
- This category contains entries 301-325.
- Attach category metadata to generated props.
- Use category weighting by level archetype.
- Combine with freshness and contradiction metadata.

## Codex Instructions
- Before placing one of these traces, read the specific atomic prompt file.
- Do not place all entries from a category in one area.
- If a trace feels like decoration, remove it.

## Common Failure Modes
- Prop clutter.
- Overtelling the implied story.
- Using traces without physical plausibility.
- Turning evidence into a linear quest.
