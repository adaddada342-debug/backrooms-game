# Existential scale shock

## Purpose
Psychological progression stage: Existential scale shock.

## Source Extract
Dominant feeling: “This place is larger than humanity.”

What the game should do: Reveal infrastructures, recursions, impossible sectors, giant emptinesses

What the player starts doing: Stop thinking in rooms; start thinking in systems

## Design Rules
- Dominant feeling must be: “This place is larger than humanity.”
- Game action: Reveal infrastructures, recursions, impossible sectors, giant emptinesses
- Expected player behaviour: Stop thinking in rooms; start thinking in systems

## Implementation Notes
- Prefer data-driven definitions, stable schemas, and testable systems.
- Any future code must be traceable back to a design rule or emotional target.
- If a mechanic makes the player feel powerful, safe, or fully certain, justify it as temporary and suspicious.
