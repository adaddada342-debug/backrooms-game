# False familiarity

## Purpose
Psychological progression stage: False familiarity.

## Source Extract
Dominant feeling: “I think I understand how this place works.”

What the game should do: Let the player form rules and reliable micro-routes

What the player starts doing: Build rituals, start trusting landmarks

## Design Rules
- Dominant feeling must be: “I think I understand how this place works.”
- Game action: Let the player form rules and reliable micro-routes
- Expected player behaviour: Build rituals, start trusting landmarks

## Implementation Notes
- Prefer data-driven definitions, stable schemas, and testable systems.
- Any future code must be traceable back to a design rule or emotional target.
- If a mechanic makes the player feel powerful, safe, or fully certain, justify it as temporary and suspicious.

## Codex Instructions
