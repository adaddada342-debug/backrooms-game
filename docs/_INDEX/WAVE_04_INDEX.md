# Wave 04 Index

## Theme
Environmental storytelling, traces, implied human absence, and prop logic.

## File Count
This wave contains `500` atomic environmental prompt files plus system, taxonomy, checklist, index, source, and tooling files.

## Why This Wave Exists
The uploaded report states that evidence of people is scarier than people themselves because it preserves absence while proving presence. Wave 04 turns that insight into a production system.

## Main Folders

- `20_ENVIRONMENTAL_STORYTELLING_SYSTEM`: core philosophy and design law.
- `21_TRACE_TAXONOMY`: categories of traces and what they mean emotionally.
- `22_TRACE_IMPLEMENTATION_RULES`: how to place traces in levels and procedural generators.
- `23_ENVIRONMENTAL_STORYTELLING_LIBRARY`: all 500 prompts split into atomic files.
- `24_CODEX_TRACE_BEHAVIOR`: rules for AI agents when placing props and clues.
- `99_SECTION_MIRRORS`: extracted source report sections.

## Non-Negotiable
A prop is never just a prop. It must function as evidence, contradiction, memory, maintenance residue, survival residue, or question generator.
