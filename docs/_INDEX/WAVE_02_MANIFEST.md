# Wave 02 Manifest

## Theme
Psychology, liminality, absence, and eerie exploration.

Wave 01 established the project spine. Wave 02 gives Codex the emotional machinery that prevents the game from becoming a generic procedural maze.

## Non-Negotiable Emotional Thesis
The player should not primarily fear being attacked. The player should fear that:

- the environment is too large to understand,
- absence is behaving like presence,
- ordinary architecture is losing its reliability,
- familiarity is becoming contaminated,
- and their own adaptation to the place is becoming disturbing.

## Source Core
The report identifies the Backrooms as an affective design problem, not a lore compendium. It emphasizes liminality, uncanny architecture, nostalgia, environmental psychology, spatial disorientation, isolation, derealisation-like unreality, and curiosity-driven exploration.

## What Wave 02 Adds

- Psychological design principles.
- Liminal-space implementation rules.
- Uncanny architecture rules.
- Nostalgia and memory contamination rules.
- Absence and isolation rules.
- Curiosity-to-dread pacing rules.
- Psychological validation checklists.

## How Codex Must Use This Wave
Before editing any gameplay, level, audio, VR, or procedural system that affects mood, Codex must retrieve at least one relevant document from this wave.

The AI must never default to monsters, gore, loud events, constant danger, or chase logic unless explicitly instructed. Even then, it must preserve absence as the main emotional engine.
