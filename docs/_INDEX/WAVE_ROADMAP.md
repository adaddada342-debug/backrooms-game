## Source Extract
# Wave Breakdown

1. **Wave 01: Brain + Vision + Core Principles** - master operating brain, source mirror, project thesis, failure modes, core principles, psychological progression, ideal game spine.
2. **Wave 02: Psychology + Liminality** - absence horror, nostalgia, derealisation, curiosity, isolation, uncanny places, solitude, memory logic.
3. **Wave 03: Architecture + Level Design** - typologies, airports, hotels, malls, offices, schools, poolrooms, roads, thresholds, procedural level theses.
4. **Wave 04: Procedural Generation** - recipes, grammars, seed systems, anomaly budgeting, validation, chunking, streaming, route memory.
5. **Wave 05: Environmental Storytelling** - 500+ object traces split into atomic files and implementation patterns.
6. **Wave 06: Audio + Survival + Multiplayer + VR** - hum systems, silence events, expedition survival, noclip anchors, multiplayer loneliness, VR presence.
7. **Wave 07: AI Agent Rules + Engine + Assets + Testing** - Codex/Cursor task contracts, Unity/Unreal implementation, asset pipeline, credit tracking, validation.

## Design Rules
- Preserve the Backrooms as an affective, architectural, liminal experience rather than a monster-first horror game.
- Every feature must serve scale, absence, isolation, mystery, uncertainty, exploration, or spatial wrongness.
- Do not solve unease with constant threat, lore dumping, entities, or objective spam.

## Implementation Notes
- Prefer data-driven definitions, stable schemas, and testable systems.
- Any future code must be traceable back to a design rule or emotional target.
- If a mechanic makes the player feel powerful, safe, or fully certain, justify it as temporary and suspicious.

## Codex Instructions
- Read related files before implementation.
- Do not invent new mechanics that contradict the emotional target.
- When uncertain, preserve ambiguity and ask for a design decision rather than filling with generic horror.
