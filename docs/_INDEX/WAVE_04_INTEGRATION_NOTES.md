# Wave 04 Integration Notes

## Integration Purpose
Add environmental storytelling as an atomic retrieval library.

## How Codex Should Use It
When asked to build or decorate a level:

1. Determine level archetype.
2. Determine emotional stage.
3. Pick 1-3 trace categories, not all categories.
4. Read relevant trace category files.
5. Place a small number of high-meaning objects.
6. Validate each object with the question test.

## Prop Density Rule
The more empty a level is, the more powerful a trace becomes.
Do not overpopulate spaces with evidence. Sparse traces hit harder.

## Conflict Rule
If a proposed prop does not create a question, remove it.
