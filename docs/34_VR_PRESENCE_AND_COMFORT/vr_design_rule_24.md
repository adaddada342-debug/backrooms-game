# VR Design Rule 24

## Archive Wave
Wave 06 - Audio, VR, Multiplayer, Global Discovery, Performance, and Validation.

## Category
VR Presence And Comfort

## Purpose
Atomic VR design and implementation rule #24.

## Emotional Target
VR should intensify liminality without creating discomfort.

## Design Rules
- Comfort is mandatory.
- Physical scale matters.
- No forced camera motion.
- Diegetic tools over HUD.

## Implementation Notes
- Support OpenXR-ready abstraction.
- Keep desktop and VR input layers separate but equivalent.
- Profile VR separately.

## Codex Instructions
- Do not add VR as an afterthought.
- Mark any feature that is desktop-only.

## Common Failure Modes
- Motion sickness.
- Flat-screen assumptions.
- Overloaded hand interactions.
- Tiny UI text.

## Source Thesis Alignment
This file follows the project thesis that the Backrooms should be designed as an affective system: absence, liminality, uncanny architecture, spatial uncertainty, nostalgia, and curiosity turning into dread. Do not convert these systems into generic monster horror, combat loops, or certainty-heavy quest design.
