# VR Survival Interactions

## Purpose
VR interactions should be physical but not exhausting.

## Design Rules
- Survival supports exploration.
- Few items, strong meaning.
- No farms, mining, factories, or combat economy.
- Pressure should come from distance, ambiguity, and limited comfort.

## Implementation Notes
Implement small data models first: item definitions, inventory slots, consumption rules, rest points, save hooks.

## Codex Instructions
Cut any mechanic that makes the player farm rather than explore.

## Common Failure Modes
- Treating this as generic survival or horror content.
- Adding complexity before the base loop proves itself.
- Ignoring scale, silence, absence, and uncertainty.
