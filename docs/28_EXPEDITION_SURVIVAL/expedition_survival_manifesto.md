# Expedition Survival Manifesto

## Purpose
Survival exists to support long expeditions, not to become Minecraft farming or spreadsheet maintenance.

## Design Rules
- Few resources, high meaning.
- Almond water, batteries, sleeping bag, anchors, tape/chalk, camera/map tools.
- No ore grind.
- No farm loops.
- No massive base building.
- Resource pressure should make distance matter.

## Implementation Notes
Implement lightweight inventory, supply consumption, rest mechanics, battery drain, water use, and expedition planning. Tune slowly.

## Codex Instructions
Keep survival mechanics atmospheric. If a mechanic makes the player stare at menus instead of space, cut it.

## Common Failure Modes
- Treating this as generic survival or horror content.
- Adding complexity before the base loop proves itself.
- Ignoring scale, silence, absence, and uncertainty.
