## Emotional Target
Sound should produce inference rather than direct explanation.

## Design Rules
- Ambiguity first.
- Diegetic plausibility first.
- Psychological effect over volume.

## Implementation Notes
- Use spatial audio.
- Use dynamic reverb zones.
- Create per-archetype acoustic profiles.

## Codex Instructions
- Validate by playtest notes, not just waveform correctness.

## Common Failure Modes
- Too loud.
- Too obvious.
- Resolved into a visible monster every time.

## Source Thesis Alignment
This file follows the project thesis that the Backrooms should be designed as an affective system: absence, liminality, uncanny architecture, spatial uncertainty, nostalgia, and curiosity turning into dread. Do not convert these systems into generic monster horror, combat loops, or certainty-heavy quest design.
