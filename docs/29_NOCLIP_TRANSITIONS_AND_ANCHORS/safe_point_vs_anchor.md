# Safe Point vs Anchor

## Purpose
Sleeping bags and anchors overlap but are not identical.

## Design Rules
- Noclip is rupture.
- Anchors create fragile trust.
- Transitions should preserve mystery.
- Every transition must be deterministic enough to debug.

## Implementation Notes
Start with one controlled noclip transition between two test levels, then add anchors, logs, and validation.

## Codex Instructions
Do not build a level select menu disguised as noclip.

## Common Failure Modes
- Treating this as generic survival or horror content.
- Adding complexity before the base loop proves itself.
- Ignoring scale, silence, absence, and uncertainty.
