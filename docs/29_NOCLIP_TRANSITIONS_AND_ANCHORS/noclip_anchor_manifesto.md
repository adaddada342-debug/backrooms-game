# Noclip Anchors and Transitions Manifesto

## Purpose
Noclipping is not just teleporting. It is the central rupture between familiar reality and impossible interior systems.

## Design Rules
- Transitions must feel physical, disorienting, and rare enough to matter.
- Anchors create temporary trust, not permanent ownership.
- Anchor placement is a serious decision.
- Some routes should be stable, some unstable, some disputed.
- Noclip rules should be partly discoverable, never fully domesticating.

## Implementation Notes
Create a transition graph that can link levels, unknown regions, anchors, and rare no-return events. Support seed stability and server/global discovery later.

## Codex Instructions
Never turn noclip into a fast travel menu first. Preserve uncertainty and spatial trauma.

## Common Failure Modes
- Treating this as generic survival or horror content.
- Adding complexity before the base loop proves itself.
- Ignoring scale, silence, absence, and uncertainty.
