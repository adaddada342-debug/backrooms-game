# Room Tone Library

## Archive Wave
Wave 06 - Audio, VR, Multiplayer, Global Discovery, Performance, and Validation.

## Category
Audio Design

## Purpose
Each archetype needs a room tone palette.

## Emotional Target
Spaces feel real because they have subtle acoustic personality.

## Design Rules
- Office tone differs from airport tone.
- Poolrooms need water-dampened reverb.
- Hotels should feel padded and air-conditioned.

## Implementation Notes
- Create ScriptableObject/asset data for room tone.
- Support procedural selection.

## Codex Instructions
- Make room tone data-driven.

## Common Failure Modes
- Over-scoring emotion.
- Turning ambiguity into monster foreshadowing.
- Using sound only as background filler.

## Source Thesis Alignment
This file follows the project thesis that the Backrooms should be designed as an affective system: absence, liminality, uncanny architecture, spatial uncertainty, nostalgia, and curiosity turning into dread. Do not convert these systems into generic monster horror, combat loops, or certainty-heavy quest design.
