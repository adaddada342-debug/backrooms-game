# Audio Comfort To Dread Curve

## Archive Wave
Wave 06 - Audio, VR, Multiplayer, Global Discovery, Performance, and Validation.

## Category
Audio Design

## Purpose
Define progression from calming ambience to oppressive unease.

## Emotional Target
Wonder becomes dread by familiarity becoming hostile.

## Design Rules
- Early spaces can be soothing.
- Mid spaces introduce uncertainty.
- Late spaces weaponise absence.

## Implementation Notes
- Tie audio mix to psychological stage.
- Avoid obvious music escalation.

## Codex Instructions
- Implement stage-based mix profiles.

## Common Failure Modes
- Over-scoring emotion.
- Turning ambiguity into monster foreshadowing.
- Using sound only as background filler.

## Related Files
- 33_ACOUSTIC_PSYCHOLOGY
- 37_GLOBAL_DISCOVERY_EVENTS

## Source Thesis Alignment
This file follows the project thesis that the Backrooms should be designed as an affective system: absence, liminality, uncanny architecture, spatial uncertainty, nostalgia, and curiosity turning into dread. Do not convert these systems into generic monster horror, combat loops, or certainty-heavy quest design.
