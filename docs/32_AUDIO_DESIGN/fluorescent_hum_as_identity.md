# Fluorescent Hum As Identity

## Archive Wave
Wave 06 - Audio, VR, Multiplayer, Global Discovery, Performance, and Validation.

## Category
Audio Design

## Purpose
Define fluorescent hum as the sonic signature of artificial endlessness.

## Emotional Target
A constant system-life that makes absence feel maintained.

## Design Rules
- Hum should vary subtly by sector.
- Hum can disappear as an event.
- Hum must not become annoying too quickly.

## Implementation Notes
- Layer buzz, ballast vibration, electrical whine.
- Use distance, occlusion, and room size to vary it.

## Codex Instructions
- Build a hum profile object per level archetype.

## Common Failure Modes
- Over-scoring emotion.
- Turning ambiguity into monster foreshadowing.
- Using sound only as background filler.

## Source Thesis Alignment
This file follows the project thesis that the Backrooms should be designed as an affective system: absence, liminality, uncanny architecture, spatial uncertainty, nostalgia, and curiosity turning into dread. Do not convert these systems into generic monster horror, combat loops, or certainty-heavy quest design.
