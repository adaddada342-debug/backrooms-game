# 445 - A bird trapped in the vestibule but never seen near the actual outside

## Category
Thresholds and false outsides

## Trace Object
A bird trapped in the vestibule but never seen near the actual outside

## Psychological Function
threshold as ecological snare

## Story Question
how did it enter?

## Purpose
Use this as an environmental storytelling trace that implies a story without showing the actor or explaining the event.

## Emotional Target
A small piece of human evidence inside an inhuman or empty place.

## Design Rules
- Place this only where the object physically and socially makes sense, unless intentionally using category contamination.
- Preserve absence: do not immediately reveal the person or cause behind it.
- The trace should create the listed question in the player’s mind.
- Use realistic scale, material, wear, lighting, and placement.
- If the object becomes decorative clutter, remove it.

## Codex Instructions
- Do not add monsters to explain this trace.
- Do not write a long note explaining this trace.
- Do not place this in every level.
- If using this procedurally, define allowed surfaces, allowed level archetypes, and exclusion rules first.

## Common Failure Modes
- Turning the trace into a quest marker.
- Overexplaining the implied story.
- Placing it randomly with no architectural context.
- Using it too often until it stops feeling special.
