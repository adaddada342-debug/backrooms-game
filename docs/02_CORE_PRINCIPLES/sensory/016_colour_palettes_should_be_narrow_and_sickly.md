# Colour palettes should be narrow and sickly

## Purpose
Atomic core principle from the Sensory category.

## Source Extract
**Colour palettes should be narrow and sickly.** Why: strong chromatic identities make levels mnemonic and emotionally sealing. Example: mono-yellow; pool-blue; nicotine beige. In game: limit palette families, then let rare accent colours matter.
