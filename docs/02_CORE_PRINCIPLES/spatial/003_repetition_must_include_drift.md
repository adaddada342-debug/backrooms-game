# Repetition must include drift

## Purpose
Atomic core principle from the Spatial category.

## Source Extract
**Repetition must include drift.** Why: repetition induces monotony; drift induces suspicion. Example: recurring room shells with altered ceilings or wall spacing. In game: keep modules related, not identical.
