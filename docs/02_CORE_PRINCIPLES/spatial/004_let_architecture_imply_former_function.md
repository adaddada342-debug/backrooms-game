# Let architecture imply former function

## Purpose
Atomic core principle from the Spatial category.

## Source Extract
**Let architecture imply former function.** Why: purposeless randomness is forgettable; implied function invites reconstruction. Example: a service corridor, showroom, locker wing, motel run. In game: design spaces as if they once worked.
