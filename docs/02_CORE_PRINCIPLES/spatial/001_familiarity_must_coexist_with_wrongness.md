# Familiarity must coexist with wrongness

## Purpose
Atomic core principle from the Spatial category.

## Source Extract
**Familiarity must coexist with wrongness.** Why: pure strangeness is noise, but familiar patterns violated in small ways are uncanny. Example: Level 0’s office-retail grammar plus impossible scale. In game: use recognisable typologies, then bend proportions, topology, or use patterns.
