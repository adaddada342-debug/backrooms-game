# Scale changes should be rare and devastating

## Purpose
Atomic core principle from the Spatial category.

## Source Extract
**Scale changes should be rare and devastating.** Why: constant spectacle desensitises. Example: an ordinary office opening into a hangar-sized duplicate of itself. In game: reserve macro-scale shocks for narrative thresholds.
