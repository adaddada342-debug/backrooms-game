# Trace Prompting Protocol

## Purpose
How to ask Codex for environmental detail generation.

## Emotional Target
controlled creativity

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Prompt must include level archetype, emotional stage, trace density, allowed categories, disallowed categories.
- Never ask for random spooky props.
- Require output as data with question metadata.

## Implementation Notes
- Suggested output columns: Prop, Category, Location, Freshness, Question, WhyItWorks, FailureRisk.

## Codex Instructions
- Follow this before adding authored or procedural environmental details.
- Prefer fewer, stronger traces.
- Preserve the project thesis: absence, scale, wrongness, curiosity.

## Common Failure Modes
- Monster explanations.
- Decoration spam.
- Lore dump notes.
- Quest clutter.
- Jumpscare setup disguised as environmental storytelling.
