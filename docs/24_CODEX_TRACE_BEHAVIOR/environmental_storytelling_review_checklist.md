# Environmental Storytelling Review Checklist

## Purpose
Review pass for authored and procedural environments.

## Emotional Target
quality control against slop

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Does each trace create a question?
- Is absence preserved?
- Is density restrained?
- Does the trace fit the architecture?
- Does the trace support the level thesis?
- Is there too much explanation?

## Implementation Notes
- Make this a pre-merge checklist for level generation changes.

## Codex Instructions
- Follow this before adding authored or procedural environmental details.
- Prefer fewer, stronger traces.
- Preserve the project thesis: absence, scale, wrongness, curiosity.

## Common Failure Modes
- Monster explanations.
- Decoration spam.
- Lore dump notes.
- Quest clutter.
- Jumpscare setup disguised as environmental storytelling.
