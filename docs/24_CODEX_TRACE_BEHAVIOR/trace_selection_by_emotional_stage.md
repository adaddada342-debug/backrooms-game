# Trace Selection by Emotional Stage

## Purpose
Match traces to the psychological progression model.

## Emotional Target
emotionally paced evidence

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Early stages: familiar, calming, lightly wrong traces.
- Mid stages: contradiction, pattern betrayal, recent absence.
- Late stages: scale, machine persistence, timekeeping, self-loss.

## Implementation Notes
- Use stage weights in procedural recipes.
- Do not deploy late-game existential traces in the first five minutes.

## Codex Instructions
- Follow this before adding authored or procedural environmental details.
- Prefer fewer, stronger traces.
- Preserve the project thesis: absence, scale, wrongness, curiosity.

## Common Failure Modes
- Monster explanations.
- Decoration spam.
- Lore dump notes.
- Quest clutter.
- Jumpscare setup disguised as environmental storytelling.
