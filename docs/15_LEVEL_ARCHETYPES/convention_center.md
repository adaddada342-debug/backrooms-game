# Convention Center

## Purpose
Define the 'Convention Center' Backrooms level archetype for authored and procedural generation.

## Emotional Target
temporary community erased

## Design Rules
- Base typology: signage, booths, carpet, name badges, empty halls.
- Do not add monsters as the core hook.
- Use absence, scale, repetition, and traces.
- Give the archetype one dominant contradiction.

## Implementation Notes
- Create modular kits for public zones, private/service zones, transition zones, and rare anomaly rooms.
- Define material palette, lighting profile, sound bed, and navigation grammar.
- Generate at least one signature impossible macro-space.

## Codex Instructions
- Before building, write the emotional thesis in the LevelRecipe.
- Generate plausible layout first, then controlled wrongness.
- Preserve realism through scale, signage, material wear, and acoustic identity.

## Common Failure Modes
- Making a generic reskin of Level 0.
- Too many random anomalies.
- A level that looks interesting but has no emotional job.
