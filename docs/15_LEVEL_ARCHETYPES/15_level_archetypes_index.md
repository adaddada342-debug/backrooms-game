# 15 Level Archetypes Index

## Purpose
Canonical liminal location families for procedural and authored levels.

## Global Wave 03 Principle
A Backrooms level is not a set of random rooms. It is a familiar place whose normal purpose has been severed, extended, contradicted, or made impossible.

## Codex Reading Rule
Read this folder only when the task involves level design, architecture, procedural generation, environmental layout, realism, or space-specific implementation.
