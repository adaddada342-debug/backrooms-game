- Mystery preservation in communications.
- Credits transparency.
- Storage control.

## Implementation Notes
- Version builds.
- Maintain changelogs.
- Track live events.
- Support cache management.

## Codex Instructions

## Common Failure Modes
- Overpromising infinity.
- Spoiling mysteries in patch notes.
- Storage hostage design.
- Uncredited assets.
