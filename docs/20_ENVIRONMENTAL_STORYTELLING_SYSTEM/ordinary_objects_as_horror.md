# Ordinary Objects as Horror

## Purpose
Ordinary objects are powerful because they preserve the real-world grammar of place.

## Emotional Target
familiarity becoming suspicious

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Prefer bottles, signs, chairs, keys, maps, towels, clocks, tools, tape, receipts.
- Do not overuse symbolic occult objects.
- Let banal specificity carry dread.

## Implementation Notes
- Use physically plausible placement and wear.
- Add small contradictions: dampness indoors, freshness in decay, order in abandonment.

## Codex Instructions
- Reject flashy set dressing unless it supports liminality.

## Common Failure Modes
- Using props as filler.
- Explaining too much.
- Creating quest clutter.
- Making traces too dramatic too often.
