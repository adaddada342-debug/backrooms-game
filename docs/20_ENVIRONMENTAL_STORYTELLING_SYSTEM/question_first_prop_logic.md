# Question-First Prop Logic

## Purpose
Every environmental object must create a question before it creates decoration.

## Emotional Target
curiosity curdling into dread

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- The question must be specific.
- The question must not be answered immediately.
- The prop must belong to the architecture yet feel slightly wrong.

## Implementation Notes
- Store a question string in metadata for procedural traces.
- Use traces as seeds for environmental chains.

## Codex Instructions
- Generate the prop only if its question survives a validation pass.

## Common Failure Modes
- Using props as filler.
- Explaining too much.
- Creating quest clutter.
- Making traces too dramatic too often.
