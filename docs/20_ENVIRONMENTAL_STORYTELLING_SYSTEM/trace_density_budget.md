# Trace Density Budget

## Purpose
Sparse traces are more powerful than clutter.

## Emotional Target
loneliness sharpened by a single object

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Use few high-value traces per region.
- Increase trace density only in refuge, camp, bureaucratic, or service areas.
- Empty rooms should remain empty.

## Implementation Notes
- Per chunk: 0-3 minor traces, 0-1 major trace, rare signature trace.
- Let procedural systems reserve silence/emptiness as valid output.

## Codex Instructions
- Do not decorate every room. Interior design is not the point, apparently shocking news to prop scatter tools.

## Common Failure Modes
- Using props as filler.
- Explaining too much.
- Creating quest clutter.
- Making traces too dramatic too often.
