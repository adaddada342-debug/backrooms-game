# Trace Chains

## Purpose
A trace chain is a sequence of environmental evidence that suggests a story without completing it.

## Emotional Target
investigation without closure

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Chains need beginning, complication, and unresolved end.
- Never force a single canonical interpretation.
- Use contradictions between traces.

## Implementation Notes
- Example: hand-drawn arrow -> empty sleeping bag -> missing anchor -> radio hiss.
- Generate chains across multiple chunks with persistence.

## Codex Instructions
- Do not make trace chains feel like fetch quests.

## Common Failure Modes
- Using props as filler.
- Explaining too much.
- Creating quest clutter.
- Making traces too dramatic too often.
