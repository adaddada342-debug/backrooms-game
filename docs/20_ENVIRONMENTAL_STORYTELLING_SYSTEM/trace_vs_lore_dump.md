# Trace vs Lore Dump

## Purpose
A trace should intensify mystery rather than explain canon.

## Emotional Target
interpretive hunger

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Avoid long documents explaining what happened.
- Prefer short fragments, forms, labels, and material clues.
- Let the player assemble theories.

## Implementation Notes
- Documents should be physical objects with context.
- Limit readable text length and make it partial.

## Codex Instructions
- If a note explains the Backrooms, delete it.

## Common Failure Modes
- Using props as filler.
- Explaining too much.
- Creating quest clutter.
- Making traces too dramatic too often.
