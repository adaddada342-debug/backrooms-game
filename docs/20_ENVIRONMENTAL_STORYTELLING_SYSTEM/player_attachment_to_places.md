# Player Attachment to Places

## Purpose
Traces help players remember rooms and emotionally attach to routes.

## Emotional Target
small human meaning in impossible scale

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Give key routes distinctive micro-evidence.
- Let player camps accumulate trace history.
- Make ordinary rooms become personal landmarks.

## Implementation Notes
- Persist player-placed traces and procedural landmark traces.
- Use object memory to support navigation without making perfect maps.

## Codex Instructions
- Do not turn every landmark into a glowing UI marker.

## Common Failure Modes
- Using props as filler.
- Explaining too much.
- Creating quest clutter.
- Making traces too dramatic too often.
