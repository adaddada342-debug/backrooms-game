# Trace Freshness Gradient

## Purpose
Trace freshness controls how close absence feels to presence.

## Emotional Target
the feeling of just missing someone

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Use multiple freshness levels: ancient, old, recent, seconds-ago, active.
- Seconds-ago traces should be rare.
- Freshness should not always imply danger.

## Implementation Notes
- Metadata field: TraceFreshness = Ancient/Old/Recent/Immediate/Active.
- Audio and materials should support freshness: steam, warmth, wetness, motion.

## Codex Instructions
- Do not spam immediate traces. They become cheap.

## Common Failure Modes
- Using props as filler.
- Explaining too much.
- Creating quest clutter.
- Making traces too dramatic too often.
