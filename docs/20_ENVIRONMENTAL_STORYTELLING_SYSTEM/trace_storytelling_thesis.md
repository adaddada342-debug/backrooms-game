# Trace Storytelling Thesis

## Purpose
Environmental storytelling in this project is not lore delivery. It is the art of leaving evidence without witnesses.

## Emotional Target
quiet unease caused by unfinished human activity

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Use traces to imply events, routines, and absences.
- Never explain the trace fully.
- Prefer ordinary objects with precise context over spectacular horror props.
- Evidence must produce a question.

## Implementation Notes
- Tag traces by category, freshness, implied actor, implied routine, and contradiction.
- Use trace clusters sparingly; one strong object can carry a room.
- Allow traces to recur as motifs across levels.

## Codex Instructions
- Before placing a prop, define the question it creates.
- If the trace answers more than it asks, reduce it.
- Reject gore-first or monster-first substitutions.

## Common Failure Modes
- Using props as filler.
- Explaining too much.
- Creating quest clutter.
- Making traces too dramatic too often.
