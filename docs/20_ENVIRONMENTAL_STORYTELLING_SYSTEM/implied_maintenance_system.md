# Implied Maintenance System

## Purpose
Maintenance traces imply hidden process, invisible workers, or autonomous infrastructure.

## Emotional Target
a dead place that is still cared for

## Source Basis
Derived from the uploaded Backrooms research report and its environmental storytelling library.

## Design Rules
- Use repaired lights, mopped strips, fresh filters, active machines.
- Do not reveal maintainers too early or perhaps ever.
- Maintenance should be selective and suspicious.

## Implementation Notes
- Create maintenance event tags for procedural placement.
- Use date stickers, mismatched tiles, changed bulbs, cleaning residue.

## Codex Instructions
- Reject maintenance traces that make the level feel safely managed.

## Common Failure Modes
- Using props as filler.
- Explaining too much.
- Creating quest clutter.
- Making traces too dramatic too often.
