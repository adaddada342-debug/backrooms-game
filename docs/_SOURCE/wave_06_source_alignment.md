# Wave 06 Source Alignment

Wave 06 converts the research report's sensory, social, and long-term design insights into production-facing documents.

## Key extracted mandates

- Sound is structural, not decoration.
- Silence should be treated as an event.
- Players should hear things they cannot verify.
- Multiplayer must preserve loneliness.
- Global discovery should feel archival, contested, and expeditionary.
- Long-term progression should be epistemic rather than a power fantasy.
- Validation must test emotional effect, not just technical correctness.
