# Wave 07 Source Alignment

Wave 07 does not introduce a new emotional thesis. It locks the entire archive into a production operating system.

It exists because the source report repeatedly warns against:

- monster-first Backrooms design
- lore bloat
- over-explanation
- randomness without grammar
- generic abandoned hallway design
- horror tricks that replace dread with ordinary danger

Wave 07 turns those warnings into operational controls for Codex, Cursor, GPT agents, MCP tools, and future build pipelines.
