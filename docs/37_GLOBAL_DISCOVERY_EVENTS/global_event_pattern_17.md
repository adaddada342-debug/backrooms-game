# Global Event Pattern 17

## Archive Wave
Wave 06 - Audio, VR, Multiplayer, Global Discovery, Performance, and Validation.

## Category
Global Discovery Events

## Purpose
Template for non-combat global event #17.

## Emotional Target
A global event should create questions, not boss fights.

## Design Rules
- No boss raids.
- No combat-first event design.
- Make events environmental, archival, sensory, or cartographic.

## Implementation Notes
- Use event manifests.
- Add start/end conditions.
- Record player observations.

## Codex Instructions
- When creating events, define the question they create.

## Common Failure Modes
- Raid design.
- Loot treadmill.
- Lore over-explanation.
- Overly frequent world changes.

## Source Thesis Alignment
This file follows the project thesis that the Backrooms should be designed as an affective system: absence, liminality, uncanny architecture, spatial uncertainty, nostalgia, and curiosity turning into dread. Do not convert these systems into generic monster horror, combat loops, or certainty-heavy quest design.
