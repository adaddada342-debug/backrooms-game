# Asset Kitbash Consistency

## Purpose
Guide Codex and content tools on 'Asset Kitbash Consistency' so spaces feel physically real instead of gamey.

## Emotional Target
The player believes the environment could exist, which makes its impossible absence more disturbing.

## Design Rules
- Realism begins with function and scale.
- Do not use cinematic horror lighting unless the level's infrastructure justifies it.
- Visible wear must imply use, maintenance, or neglect.
- Avoid overdecorating.

## Implementation Notes
- Use real-world measurement references.
- Create validation passes for texel density, scale, roughness/metallic consistency, and lighting sources.
- Keep post-processing subtle unless an anomaly justifies escalation.

## Codex Instructions
- Never assume scripts alone can create realism.
- When placing assets, explain why they belong there.
- Prefer fewer high-believability props over many random props.

## Common Failure Modes
- Asset soup.
- Over-shiny materials.
- Fake theatrical lighting.
- Scale mistakes that break immersion.
