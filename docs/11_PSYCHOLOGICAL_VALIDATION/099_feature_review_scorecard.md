# Feature Review Scorecard

Score every feature from 0-5.

| Category | Question | Score |
|---|---|---|
| Absence | Does this preserve missing social context? | 0-5 |
| Liminality | Does this feel transitional or threshold-like? | 0-5 |
| Curiosity | Does this create questions without answering too much? | 0-5 |
| Scale | Does this imply more than the player can verify? | 0-5 |
| Familiar Wrongness | Does this begin from realistic familiarity? | 0-5 |
| Restraint | Does this avoid loud horror/cliché? | 0-5 |
| Player Interpretation | Does this make players inspect/infer/compare/doubt? | 0-5 |
| Long-Form Impact | Does this support hundreds of hours of psychological progression? | 0-5 |

## Reject Threshold
If total score is under 24/40, redesign.

## Immediate Rejection Flags
- Feature is mainly a monster chase.
- Feature makes the player feel like a powerful hunter.
- Feature explains the system too completely.
- Feature replaces environment with exposition.
- Feature makes maps/objectives too certain.
