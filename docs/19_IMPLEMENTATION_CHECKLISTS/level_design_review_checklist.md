# Level Design Review Checklist

## Purpose
A practical review checklist for Codex, Cursor, or the human director before accepting work.

## Checklist
- [ ] Does the level have one emotional thesis?
- [ ] Can the level be described with one dominant image?
- [ ] Does the architecture imply former function?
- [ ] Is the contradiction clear but not overexplained?
- [ ] Does absence remain active without monsters?
- [ ] Are service/back-of-house spaces present?
- [ ] Does the player get readable landmarks?
- [ ] Does backtracking preserve familiarity while adding doubt?

## Pass Rule
A feature can compile and still fail this checklist. Do not confuse technical success with Backrooms success, humanity's favourite little mistake.

## Codex Instruction
If any checkbox fails, write a fix plan before continuing implementation.
