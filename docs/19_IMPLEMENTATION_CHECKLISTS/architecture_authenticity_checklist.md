# Architecture Authenticity Checklist

## Purpose
A practical review checklist for Codex, Cursor, or the human director before accepting work.

## Checklist
- [ ] Are doors, corridors, ceilings, stairs, and service areas plausible?
- [ ] Are room adjacencies believable before wrongness begins?
- [ ] Are signs and maps consistent with the institution?
- [ ] Are props sparse and meaningful?
- [ ] Does material wear imply use patterns?

## Pass Rule
A feature can compile and still fail this checklist. Do not confuse technical success with Backrooms success, humanity's favourite little mistake.

## Codex Instruction
If any checkbox fails, write a fix plan before continuing implementation.
