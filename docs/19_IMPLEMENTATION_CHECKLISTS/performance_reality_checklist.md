# Performance Reality Checklist

## Purpose
A practical review checklist for Codex, Cursor, or the human director before accepting work.

## Checklist
- [ ] Are generated chunks cached?
- [ ] Are meshes instanced?
- [ ] Are textures streamed?
- [ ] Are reflection/lighting systems bounded?
- [ ] Is VR target performance respected?

## Pass Rule
A feature can compile and still fail this checklist. Do not confuse technical success with Backrooms success, humanity's favourite little mistake.

## Codex Instruction
If any checkbox fails, write a fix plan before continuing implementation.
