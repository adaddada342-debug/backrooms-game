# Multiplayer Rule 06

## Archive Wave
Wave 06 - Audio, VR, Multiplayer, Global Discovery, Performance, and Validation.

## Category
Multiplayer Loneliness

## Purpose
Atomic multiplayer rule #6.

## Emotional Target
Social systems should intensify isolation rather than cancel it.

## Design Rules
- No constant crowding.
- Social contact is scarce.
- Asynchronous traces beat always-on parties.
- No PvP-first design.

## Implementation Notes
- Design sessions around shards/sectors.
- Use delayed traces and contested map sharing.
- Limit reliable communication.

## Codex Instructions
- Do not implement multiplayer features that make the Backrooms feel like a lobby.

## Common Failure Modes
- Constant voice chat comedy.
- Crowded hubs.
- Quest raids.
- PvP griefing.

## Source Thesis Alignment
This file follows the project thesis that the Backrooms should be designed as an affective system: absence, liminality, uncanny architecture, spatial uncertainty, nostalgia, and curiosity turning into dread. Do not convert these systems into generic monster horror, combat loops, or certainty-heavy quest design.
