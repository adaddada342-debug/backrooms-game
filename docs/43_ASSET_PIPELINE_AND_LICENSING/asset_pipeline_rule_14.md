## Purpose
Atomic asset pipeline rule #14.

## Emotional Target
Assets become believable traces of a real impossible place.

## Non-Negotiable Design Rules
- Track license metadata.
- Validate scale.
- Avoid mixed-style asset soup.
- Optimise before shipping.

## Implementation Notes
- Use asset manifests.
- Store credits JSON/CSV.
- Add import validation scripts.
- Separate raw and processed assets.

## Codex Instructions
- Never import random web assets without recording provenance.

## Common Failure Modes
- Missing credits.
- Bad scale.
- Overlarge textures.
- Unoptimised Sketchfab meshes.
- Legal ambiguity.
