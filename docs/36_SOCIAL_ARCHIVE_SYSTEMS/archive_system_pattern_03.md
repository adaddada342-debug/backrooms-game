# Archive System Pattern 03

## Archive Wave
Wave 06 - Audio, VR, Multiplayer, Global Discovery, Performance, and Validation.

## Category
Social Archive Systems

## Purpose
Atomic social archive pattern #3.

## Emotional Target
Shared knowledge should make the world larger, not solved.

## Design Rules
- Archive fragments.
- Preserve disagreement.
- Do not solve the whole system.
- Reward observation.

## Implementation Notes
- Represent reports as data.
- Attach provenance.
- Support verification states.

## Codex Instructions
- Design social systems as interpretive tools, not leaderboards.

## Common Failure Modes
- Global certainty.
- Wiki-style total explanation.
- Competitive stat obsession.

## Source Thesis Alignment
This file follows the project thesis that the Backrooms should be designed as an affective system: absence, liminality, uncanny architecture, spatial uncertainty, nostalgia, and curiosity turning into dread. Do not convert these systems into generic monster horror, combat loops, or certainty-heavy quest design.
